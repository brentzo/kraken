# Kraken

**Many tentacles, one beak.**

A portable control plane for coding agents.
Run as many as you want in parallel, each in its own git worktree, and integrate their branches through a merge gate instead of by hand.
The beak is that gate.
Every branch converges there, and nothing lands unless the combination holds.
Works with self-hosted forges.

Designed, not built.
There is no install and no binary yet.
